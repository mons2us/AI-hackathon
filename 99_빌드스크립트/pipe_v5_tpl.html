FormProof 파이프라인

앞에서 다룬 과제(규모, 비전문가, 학습 범위, LLM 신뢰성, 제작성, 조건 근거)를 모두 푼다고 가정한 범용 플랫폼 구조와, 지금 풀고 있는 자전거 거치대 사례입니다.

선택한 경로

사전 검증 사례 숫자는 자전거 폰 거치대 계산(2코어 CPU, 8 GB 환경)에서 확인한 값입니다. 대리 모델 경로의 속도·정확도는 아직 구현 전이라 확인이 필요합니다.

문제별 적용

문제별 물리·경로는 플랫폼을 다 만들었다고 가정한 예시 매핑입니다. 사전 검증 표시가 있는 문제만 실제 계산을 했습니다.

3인 개발 범위

팀원 A · 물리 엔진·물리 AI
  • FEM 엔진·민감도 정리 (구조·진동·열) 해커톤 전
  • 강건 무게 최소화·제작 제약 해커톤 전
  • 대리 모델 학습·오차 검사 (거치대 계열) 해커톤
  • 학습 계획 규칙 (1종) 해커톤
팀원 B · 에이전트·조건·검증
  • 설계 명세 형식·검사기 해커톤 전
  • 근거 DB (재료·제품별 하중·기준) 해커톤 전
  • 자동 검증 관문 (오늘 잡은 오류 5종) 해커톤 전
  • LLM 에이전트·경로 선택 연결 해커톤
팀원 C · 입출력·화면·데이터
  • STL·도면 자동 출력, 출력 형상 재검증 연결 해커톤 전
  • FEM 데이터 생성 배치 실행 (서버) 해커톤 전
  • 입력 처리 (스케치·이미지) 해커톤
  • 3D 결과 화면·시연 구성 해커톤
일정 (안)1주: 엔진·명세 형식·출력 자동화 → 2주: 검증 관문·근거 DB·데이터 생성 시작 → 3주: 대리 모델 학습 준비·통합 시험 → 해커톤 1일차: 에이전트 연결·대리 모델 학습 → 2일차: LLM 단독 비교 시연·전체 시연·3D 프린트 실물
다음 단계: 학습 계획 범용 자동화, 유동·전자기·음향 모듈, PINN 해석기 연계. 역할 배분은 팀원 전공에 맞춰 조정이 필요합니다.
