03바로잡은 내용

폰 회전 관성 누락이전까지 폰 + 받침대를 한 점의 질량으로 계산해 거치대 진동수가 실제보다 높게 나왔습니다(예: 41.7 g 설계 106 → 65 Hz). 지금은 모든 계산에 강체 관성을 넣었습니다.
흔들림 기준의 근거 해석 오류ISBS 2020 자료는 자갈길이 아니라 코블스톤 길, 핸들바가 아니라 바퀴 축(드롭아웃)의 위아래 가속도이고, 34.6–45.6 Hz는 최대가 아니라 중앙 진동수입니다. "45.6 Hz × 2 = 91 Hz" 기준은 폐기하고, 진동 전달 곡선(흔들림 배수)으로 판정합니다.
LLM 단독 비교의 결론 변경흔들림 배수로 보면 LLM 설계도 1.2–1.5배로 이전 최적화 설계와 비슷합니다. 비교의 핵심은 "LLM이 근거 없이 기준을 정하고(40–60 Hz), 자기 진동수 예측이 −17 ~ +42% 틀렸다"는 사실, 그리고 받침 위치까지 바꾼 최적 설계(30.6 g, 1.03배)와의 차이로 다시 정리합니다.

05팀 측정 안내 (① · ② · ③)

측정 A · 핸들바 진동 (①②)준비: 폰 1대, phyphox 앱, 케이블 타이 또는 시판 거치대
  1. phyphox에서 "가속도 (중력 제외)" 실험 선택, 기록 주기 최대로
  2. 폰을 핸들바 클램프 바로 옆에 단단히 고정 (화면 위, 폰 긴 쪽 = 앞뒤)
  3. 평지 매끈한 길 1분 → 울퉁불퉁한 길(보도블록 · 자갈 · 코블) 2분, 같은 속도 유지
  4. 앱에서 CSV 내보내기 → GitHub 03_자전거거치대/실측/에 업로드
  5. 속도와 노면 종류를 파일 이름에 기록
측정 B · 감쇠비 (③)준비: 출력한 거치대, 핸들바(또는 지름 32 mm 봉), 폰
  1. 거치대를 봉에 볼트로 고정, 폰(또는 같은 무게 추)을 올림
  2. phyphox "가속도 스펙트럼" 또는 원시 가속도 기록 시작
  3. 폰 끝을 손가락으로 툭 한 번 치고 3초 기다림, 5회 반복
  4. CSV를 같은 폴더에 업로드 → 진동이 줄어드는 속도로 감쇠비, 피크로 고유진동수 계산(제가 처리)

측정 B는 계산 예측(1차 진동수)과 실측 비교 자료도 됩니다. 테스트 키트 v1의 탭 테스트와 같은 방법입니다.
