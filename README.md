# AI-hackathon — FormProof

물리 검증이 끝난 3D 설계를 말·스케치 입력에서 자동으로 만드는 파이프라인 (FEM 위상최적화 + 물리 AI).

## 폴더
| 폴더 | 내용 |
|---|---|
| 01_제출서류 | 최종 제출본(참가신청서·첨부자료). `버전이력/`에 v1~ 전 버전 |
| 02_시연페이지 | 자전거 거치대 사례 페이지(bike_mount_v1~v7), 파이프라인 시각화(formproof_pipeline_v1~v5). 최신 = 가장 큰 번호 |
| 03_자전거거치대 | 사례 2(스케치 입력). `cad/` STL·도면, `code_3D/` 3D MMA 무게최소화(opt3d.py)·검증(verify5.py)·STL 생성(mkstl3d.py) |
| 04_TV스탠드 | 사례 1 — 중앙 받침형(pedestal/, 3.92 → 1.95 kg)과 외형 고정 블레이드 다리 추가.(텍스트 입력, 대표). 진행 중 — tvopt.py(최적화), tvverify.py(출력형상 검증), tvstl.py. 3D 덩어리 최적화 3회는 출력형상 검증 미통과(부재가 격자보다 얇음). 판재 다리(알루미늄 10 mm, 2D 평면응력 1 mm 격자)로 재정의: `plate_v2/`. 다리 1개 200 → 146 g(−27%), TV 상단 흔들림 2.2 → 0.25 mm(기준 ≤ 1 mm), 3D 재검증 통과 |
| 06_발표 | 발표 초안 PPT v1~v5와 생성 스크립트, 자전거 장착 3D 장면 렌더링(scene/) |
| 05_영상 | 설계과정·시연 영상 |
| 07_무선충전스탠드 | 사례 3(구조+열). 3D 열전도 모듈(thermal3d.py, 이론해 검증), 열·구조 동시 최적화(wcopt.py), 출력형상 검증. 팬 없이 5 W: 알루미늄 106 g, 접촉면 48.0 °C(기준 48) |
| 99_빌드스크립트 | 서류·페이지·그림 생성 스크립트 |

## 자전거 거치대 최종 결과 (3D run d)
- 조건: 자갈길 진동 34.6–45.6 Hz, 48.5 g (ISBS 2020), PETG(Prusament TDS: E 1.7 GPa, 항복 39 MPa)
- 기준: f1 ≥ 91 Hz, 응력 ≤ 26 MPa
- 결과: 기본설계 50.0 g → 39.8 g (−20%), f1 26.5 → 99.4 Hz, 최대응력 18.3 MPa (1 mm 출력형상 재검증)

## TV 스탠드
- 조건: IEC 62368-1 안정성(10° 기울임, 총중량 13% 수평력), 65" TV 20.8 kg, Al 6061-T6
- 처짐 기준(자중 1 mm, 수평력 2 mm)·스탠드 3 kg은 가정값 — 확인 필요
