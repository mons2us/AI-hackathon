FormProof 구현 목록

발표 자료가 주장하는 기능 중 아직 코드로 돌아가지 않는 것, 그리고 남은 확인 항목입니다. 위에 있을수록 먼저 합니다. 각 항목에 그 기능이 근거가 되는 장표 번호(발표 초안 v17 기준)를 적었습니다.

2026-11-15 작성 · 저장소 mons2us/AI-hackathon
코드 없음수동으로 1회 실행스크립트 따로 있음대기선택

먼저 정할 것

  • 발표 자료 제출 마감일, 발표일, 발표 시간(분)
  • 사내에서 쓸 수 있는 LLM (작업 환경에서는 외부 AI API 호출 불가 → 1·6번은 사내 환경에서 돌릴 코드로 작성)
  • 자료 2번이 마음에 안 드는 이유 (내용 / 디자인 / 둘 다)와 새 흐름(12장 안팎) 확정

A시연 필수 — 말 + 스케치에서 제작 파일까지 자동

이 묶음이 돌아가야 2·5·9·10번 장표와 시연 영상이 사실이 됩니다. 지금은 단계마다 사람이 손으로 이어 붙인 상태입니다.

A1

입력 → 설계 명세 (텍스트 + 스케치) 수동으로 1회 실행

할 일사내 LLM에 텍스트와 스케치 이미지를 넣어 설계 명세 JSON을 출력. 항목마다 출처(텍스트 / 스케치 / 근거 DB / 가정) 표시, 빠진 조건은 사용자 질문으로 반환
현재이 대화에서 Claude가 스케치를 읽어 1회 작성: 03_자전거거치대/일체형_제작형_v1/입력/FormProof_설계명세_스케치입력_v1.json
근거 장표2, 5, 6, 9, 10
A2

설계 명세 → 계산 자동 실행 수동 설정

할 일명세 JSON을 읽어 고정 부품(걸이 · 집게 하우징 · 레일) CAD 생성, 최적화 설정값(각도, 진동수 목표, 온도·처짐 제한, 폰+부품 무게, 격자 크기) 자동 입력 후 실행
현재opt_int.py에 환경변수(TILT, FT, TLIM, DLIM, GRIP, MSYS, NX)를 손으로 넣어 실행, 1회 약 66분(CPU 2코어)
근거 장표10, 11
A3

검증 관문 자동 판정 스크립트 따로 있음

할 일한 번에 판정하고 합격/불합격 리포트 출력: 흔들림(10–100 Hz), 폰 온도, 터치 처짐, 충격·층간 응력, 한 덩어리 여부, 부재 두께, 부품 간섭, 폰 고정(이탈) 점검
현재opt_int.py MODE=eval, binthick.py, 간섭 확인(cadquery)은 따로 실행. 폰 이탈 점검은 손계산만 했고 코드 없음 — 12번 장표에 "검증 항목에 추가"라고 적었으므로 반드시 구현
근거 장표8, 10, 12, 13
A4

제작 파일 자동 생성 스크립트 따로 있음

할 일최적화 결과 → 출력용 STL(정밀 하우징·구멍 결합, 물샐틈없는 메쉬) → 출력 형상 재해석 → 도면 → 조립 설명서 HTML까지 한 명령으로
현재build_body.py, vox.py, parts.py, dwg.py, dwg_body.py, 설명서는 수작업 HTML
근거 장표10, 14
A5

근거 리포트 코드 없음

할 일최종 수치, 조건별 출처, 가정값, 확인 필요 항목을 한 장으로 자동 정리
근거 장표5 (근거 리포트 박스)
A6

LLM 에이전트 루프 (불합격 → 재설계) 코드 없음

할 일A3 리포트가 불합격이면 LLM이 원인을 읽고 조건·설정을 바꿔 A2를 다시 실행
현재이번 사례의 재설계(폰 고정 추가, 레일 위치 변경, 연결부 보강)는 대화하며 사람과 Claude가 직접 판단
근거 장표5, 10 ("불합격이면 에이전트가 다시 계산")

B자료가 주장하는 입력 형식

4·6번 장표에 ✓로 적혀 있음. A1과 같은 틀(입력 → 명세 JSON)에 붙이면 됩니다.

B1

사진 입력 (실물 · 사용 환경) 코드 없음

할 일사진에서 형상·치수·사용 조건 추출 → 명세
B2

문서 · PPT 입력 (기획서 · 요구 사양서) 코드 없음

할 일사양·제약 조건 추출 → 명세
B3

특허 아이디어 입력 (청구항 · 도면) 코드 없음

할 일구조·기능 요구 추출 → 형상 후보
B4

STEP 입력 (기존 제품 개선) 코드 없음

할 일STEP을 읽어 지킬 곳 · 비울 곳 지정 → 경량화·보강 최적화

C남은 확인 · 계산

C1

스프링 시판품 사양 확정 확인 필요

할 일사용 길이 20.5 → 7.5 mm(밀착 길이 ≤ 7 mm), 바깥지름 ≤ 5 mm를 견디는 제품 찾기 → 집게 미는 힘 다시 계산
C2

잠금 나사 조임력 · M4 클램프 강도 미계산

할 일집게 벌어지는 힘 약 21 N을 잠금 마찰로 막는지, 핸들바 조임부(귀) 강도·미끄럼
C3

AI 학습(7번 장표)을 일체형 기준으로 다시 선택

현재분리형 거치대로 학습·탐색한 결과. 장표에 "(분리형 거치대)" 표시
C4

LLM 단독 비교(15번 장표)를 일체형 기준으로 다시 선택

현재분리형 거치대 조건 비교. 장표에 "분리형 거치대 · 같은 조건 비교" 표시

D발표 자료 · 영상

D1

자료 전면 재구성 대기

할 일결론 먼저, 장마다 메시지 하나, 12장 안팎. 실증은 입력 → 계산 → 검토·수정 → 결과 → 제작 순서. TV · 무선충전 · AI 학습 상세는 부록
대기 이유발표 시간, 2번 불만 이유, 흐름 확정
D2

3분 시연 영상 A 묶음 이후

할 일A1~A4가 실제로 돌아가는 화면으로 촬영, 소요 시간 실측값으로 자료 갱신
