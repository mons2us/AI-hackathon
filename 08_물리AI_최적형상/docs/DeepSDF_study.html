DeepSDF — 형상을 "숫자 32개"로 바꾸는 신경망

무엇을 배우나 · z와 거리의 차이 · 어떻게 학습하나 · 우리 파이프라인에서 어디에 쓰나 · 한계

2026-11-14 작성 · 표시: 논문 원 논문 값 실측 우리 리허설에서 잰 값 추정·가정 아직 확인 안 됨

1한 줄 요약

s = fθ( z , x )

"이 형상(z)에서, 이 점(x)은 표면까지 얼마나 떨어져 있나(s)?"에 답하는 신경망

기호뜻개수우리 설정
x공간의 한 점 좌표 (mm)묻고 싶은 만큼3개 숫자 (가로·앞뒤·높이 좌표, mm)
s그 점에서 표면까지 최소 거리. 안쪽 −, 바깥 +, 표면 0 = 부호 있는 거리(SDF)점마다 1개 (출력)±4칸(8~20 mm)에서 자름
z형상 하나의 번호표(잠재 벡터). 거리 아님형상마다 1개32개 숫자
θ신경망 가중치 — 모든 형상이 같이 씀모델에 1세트4층 × 128 (약 6만 개)
이름이 겹치는 주의점 — 좌표의 세 번째 축(높이)도 흔히 "z"라고 부르지만, DeepSDF의 z는 그것과 전혀 다른 것(형상 번호표, 숫자 32개). 이 문서에서 z는 항상 형상 번호표, 좌표는 x 하나(3개 숫자 묶음)로 씀.
흔한 오해 ✕ "z = 좌표마다 저장된 표면까지 거리" → 틀림. 좌표마다의 거리는 s이고, 저장해 두는 값이 아니라 신경망이 좌표를 받을 때마다 계산. z는 형상마다 하나뿐인 "이 형상이 뭐냐"를 뜻하는 숫자 묶음.

2SDF(부호 있는 거리)란 — 직접 눌러 보기

그림 위를 누르면 그 점의 s 값이 나옵니다

2D 예시: 고리(클램프 링) + 막대(팔) 모양. 색은 각 점의 s 값.

  • 파랑 = 형상 안쪽 (s < 0), 진할수록 깊숙이
  • 빨강 = 형상 바깥 (s > 0), 진할수록 멀리
  • 검은 선 = 표면 (s = 0)
  • 회색 등고선 = 4 mm 간격

형상은 "s = 0 인 점들의 모임"으로 정의됨. 그래서 s를 아무 좌표에서나 계산할 수 있으면 원하는 해상도로 표면을 뽑을 수 있음(마칭 큐브 등).

3칸(복셀) 대신 SDF로 표현하면 좋은 점

① 짧다

형상 하나 = 숫자 32개. 칸 1.5만 개를 직접 최적화하는 것보다 찾을 범위가 훨씬 좁음.

② 말이 되는 형상만 나옴

z 공간은 학습한 형상들 "사이"를 채우므로, z를 움직여도 떨어진 조각·잡음 칸이 잘 안 생김.

③ 미분 가능

s가 z에 대해 매끈하게 변해서, "무게를 줄이려면 z를 어느 쪽으로?"를 기울기로 계산 가능 → 최적화.

④ 출력은 매끈하게

계산(FEM·PINO)은 2 mm 칸으로 빠르게, 최종 STL은 0.5 mm 등 촘촘히 뽑아 깍둑 모양 없음.

4어떻게 학습하나 — "자동 디코더"

  • 인코더가 없음: 형상을 넣어서 z를 "계산"하는 부분이 따로 없고, z 자체가 학습 변수. 그래서 "자동 디코더(auto-decoder)"라고 부름 논문
  • 새 형상의 z 찾기: 신경망 θ는 고정하고, 그 형상의 점·거리에 가장 잘 맞도록 z만 수백 번 고침 (우리 검증: 200스텝)
  • 거리 자르기(±δ): 표면 근처만 정확하면 되므로 먼 곳의 거리는 ±δ로 잘라서 학습 (원 논문 δ=0.1, 형상 크기를 1로 맞춘 단위) 논문
  • z 크기 벌점: z가 커지지 않게 해서 z 공간이 0 주변에 모이게 함 → 최적화할 때 이상한 z로 빠지는 것을 줄임

4+z는 어떻게 정해지나 · 무엇을 학습하나 · 구조는 MLP

z = 규칙 없이 "학습되는 변수"

처음엔 형상마다 0 근처 작은 무작위 숫자 32개(평균 0, 표준편차 0.01). 학습하면서 그 형상의 거리 s를 잘 맞추는 쪽으로 z 자체를 기울기로 고침. ‖z‖² 벌점(×0.0001)으로 0 근처 유지. 비슷한 형상끼리 z가 가까워지는 것은 학습 결과로 생김(사람이 정하지 않음).

새 형상의 z = 작은 최적화

신경망 θ는 고정하고, 그 형상의 점·거리에 맞도록 z만 200~300번 고침. 최적화 단계에서도 같은 원리로 z를 움직임 (목표만 "거리 맞추기" → "가볍고 기준 통과"로 바뀜).

학습되는 파라미터크기 (그룹 하나, 형상 5,000개)역할
신경망 가중치·편향 θ54,273개 실측모든 형상이 공유하는 "z·좌표 → 거리" 규칙
z 표5,000 × 32 = 160,000개형상마다 하나 — 형상을 외우는 부분
Q. 가중치 θ와 z가 둘 다 바뀌는데 어떻게 풀리나? (하나는 고정돼야 하지 않나?)
고정되는 것은 데이터(좌표 x와 정답 거리 s)이고, 그 양이 미지수보다 압도적으로 많아서 둘 다 풀림. 1차식 비유 s = a·zi + b·x: 아는 값 = 형상 5,000개 × 점 4,000개 = 식 2,000만 개, 모르는 값 = a, b + z 5,000개 = 5,002개. 남는 모호함은 a·z = (2a)·(z/2) 같은 크기 주고받기뿐이고 s에는 영향 없음 (z 크기 벌점이 하나로 정해 줌). 추천 시스템(사용자 벡터·영화 벡터 동시 학습)과 같은 원리.
z를 무작위로 고정하고 θ만 학습해도 외우기는 되지만, 비슷한 형상끼리 z가 가깝다는 보장이 없어 z 공간이 뒤죽박죽 → z를 움직이는 최적화가 안 됨. z도 학습시키면 신경망이 비슷한 형상을 가까운 z에 스스로 배치 → 매끄러운 z 공간. 학습은 한 번에 형상 32개·점 1,024개씩 뽑아 θ와 그 형상들의 z를 동시에 조금씩 고침.
핵심은 특별한 구조가 아니라 z도 학습 변수로 둔다(인코더 없음)는 학습 방식. 원래 칸 1.5만~4만 개였던 형상이 숫자 32개로 줄어듦 = "형상을 압축해서 외우는 모델".

5우리 파이프라인에서 쓰는 방법

항목원 논문 (ShapeNet 가구·자동차)우리 (08)
z 크기256 논문32 (형상이 한 문제 안의 변형이라 단순)
신경망8층 × 512 논문4층 × 128 — 작을 수 있음(아래 한계)
형상당 점약 50만 점 논문4,000점 (표면 근처 85%)
학습 형상범주마다 수천 개 논문그룹마다 5,000개 (설계 범위 안 무작위 형상)
모델 수범주마다 1개그룹(도화지)마다 1개 → 6개
사전학습 가중치공개 코드에 가중치 없음사용 안 함 (형상 종류가 다르고 ShapeNet은 비상업 약관)

6지금까지 확인한 것과 한계

항목결과
2D 개념 검증 (100개 형상, CPU 2분)처음 보는 형상 IoU 0.991–0.996 실측
3D 리허설 (형상 200개, 1,500스텝, CPU)IoU 0.54–0.62 — 낮음 실측
3D 본 학습 (5,000개, 1만 5천 스텝)오늘 거치대 80·TV 중앙형으로 측정 예정 미측정
한계 (냉정하게)
  • 배운 것 사이만 만든다: z 공간은 학습 형상들 사이를 채울 뿐. 학습에 없는 종류의 좋은 설계(예: 아주 가는 트러스)는 표현 못 할 수 있음 → 결과가 FEM 직접 최적화보다 무거울 수 있음
  • 가는 부재가 어렵다: 2 mm 칸 2~3개 두께의 막대는 신경망이 흐리게 그리기 쉬움 → 모델이 작으면 IoU가 낮게 나옴
  • z가 학습 범위 밖으로 가면 이상한 형상: 그래서 z 크기 벌점과, 최종 FEM 검증을 반드시 함
  • 연결은 보장 안 됨: 칸으로 자를 때 끊길 수 있음 → 최적화 결과를 0/1로 자른 뒤 연결 검사 + FEM
개선 후보 (측정 결과에 따라) 신경망 키우기(8층 × 256), 좌표에 사인·코사인 특징 추가(Fourier features) 또는 SIREN 활성화로 가는 부분 표현력 향상, 형상당 점 늘리기.
