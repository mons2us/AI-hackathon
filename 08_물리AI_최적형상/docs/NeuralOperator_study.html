1한 줄 요약 — "문제 하나"가 아니라 "문제 가족"을 푼다

u = 𝒢θ( a )

입력 함수 a(형상·재료·하중 지도) 를 넣으면 출력 함수 u(변위장) 를 내는 연산자 𝒢를 신경망으로 학습

이름한 마디우리와의 관계
FNO격자 위 함수를 FFT로 주파수 공간에 보내서 섞는 연산자PINO의 몸통 (FNO3d)

2공통 뼈대 — 넷 다 "들어 올리기 → 적분층 × L → 내리기"

FNO의 𝒦

κ가 "거리만의 함수"(합성곱)라고 가정 → FFT 후 낮은 주파수에 가중치 곱. 전 영역을 한 번에 섞음.

GNO의 𝒦

반지름 r 안의 이웃 점만 더함. κ(x,y)는 작은 MLP. 메시 모양이 자유롭지만 국소적.

PINO / PI-GNO

𝒦는 위 둘 중 하나 그대로. 손실에 물리 방정식 잔차를 더하는 것만 다름.

근거: 신경 연산자 = "선형 적분 연산자 + 점별 비선형 활성화"를 층층이 쌓은 구조로 정의 논문 [1][3]. "격자가 달라도 같은 가중치"(이산화 불변)가 일반 CNN과의 핵심 차이.

3FNO — 주파수 공간에서 섞기

직접 해 보기 — 남기는 주파수 개수(modes)에 따라 무엇이 사라지나

modes = 8 회색 = 원래 신호(얇은 막대 + 덩어리 = 우리 형상의 단면 느낌), 초록 = 낮은 modes개만 남겨 복원

내용
장점FFT라 계산량 약 N log N, 한 층에서 영역 전체가 섞임 → 하중이 멀리 전달되는 탄성 문제에 맞음. 원 논문: 256×256 Navier–Stokes 추론 0.005 s vs 의사 스펙트럴 풀이 2.2 s 논문 [2]
단점 ①규칙 격자 전용. 곡면·불규칙 메시는 격자로 바꾸거나 Geo-FNO처럼 좌표 변환 필요 [5]
단점 ②FFT는 주기 경계를 가정 → 끝이 이어진 것처럼 섞임. 그래서 우리 코드는 4칸 pad 후 잘라냄
단점 ③낮은 modes만 쓰니 날카로운 경계·얇은 부재를 놓치기 쉬움 → 우리 코드는 3×3×3 합성곱(loc)을 나란히 붙여 국소 정보 보완
우리 코드 (fp08/models.py FNO3d): 입력 9채널 → 폭 24 → 스펙트럴 합성곱(modes 8×8×8) + 3×3×3 합성곱 × 4층 → 출력 = 하중 케이스마다 변위 3성분. 격자 크기가 그룹마다 달라도 같은 가중치(그래서 PINO가 그룹이 아니라 제품마다 1개)

4PINO — FNO에 "물리 채점"을 더한 학습법

원 논문의 두 단계 논문 [4]

단계하는 일우리 사용
① 연산자 학습여러 문제(형상)로 데이터 + 물리 손실을 함께 학습. 데이터는 거친 해상도, 물리는 고운 해상도에 걸 수 있음✅ 사용 (그룹 6개 × 형상 수천 개)
② 문제별 미세 조정시험 시 그 문제 하나에 대해 물리 손실만으로 가중치를 더 조정 → 오차 더 감소⏳ 선택 사항 (최적화 중 요청마다 하면 속도 이점이 줄어듦 추정)

"물리 손실"의 미분을 어떻게 구하나 — 여기서 모델들이 갈린다

방법원리문제점
푸리에 미분FFT에서 ik를 곱하면 미분주기·매끈함 가정. 우리 형상(재료/빈칸 경계)에는 부적합 → 사용 안 함
유한 차분이웃 칸 값의 차격자 오차, 경계에서 부정확
자동 미분신경망을 좌표로 미분FNO는 출력이 격자값이라 좌표 미분이 바로 안 됨 (GNO도 원래는 안 됨 → 6절 mGNO)
FEM 강성행렬 K (우리)신경망 미분 없이 잔차 r = Kû − f를 FEM과 같은 행렬로 계산K 조립 비용. 하지만 FEM 코드(fem.py) 재사용 → 정답 FEM과 같은 이산화라 일관됨
리허설에서 배운 것 실측 — 원래 쓰려던 에너지 손실 ½ûᵀKû − fᵀû는 학습 초기 값이 수천 배로 커져 데이터 손실을 덮음 → 야코비 전처리 잔차 + 크기 오차(log)로 교체 (정답이면 0). 또 float32 물리 계산은 폰 기둥(강체) 부분에서 에너지 오차 약 5% → float64로.
냉정하게: 원 논문은 PINO가 데이터 없이 물리만으로도 학습된다고 보고 논문했지만, 우리 리허설에서 형상 100개로는 검증 오차가 오히려 나빠짐(과적합), 1,000개에서도 변위장 L2 0.38~0.74로 관문(10%) 미달 실측. "물리 손실을 넣으면 데이터가 적어도 된다"는 우리 문제에서 아직 증명 안 됨 — 월요일 PINO vs FNO 비교 실험이 이걸 확인하는 실험.

5GNO — 점을 그래프로 잇고 이웃끼리 섞기 (+ GINO)

(𝒦v)(x) = Σy ∈ Br(x) κθ(x, y, a(x), a(y)) · v(y)

반지름 r 공 안의 이웃 y만 더함 · κ는 작은 MLP · 점이 어디 있든(불규칙 메시) 상관없음 [1]

직접 해 보기 — 점을 클릭하면 그 점이 섞는 이웃이 보임

반지름 r = 45 px
내용
장점FEM 메시·점구름 그대로 입력. 곡면·구멍·두께 변화가 격자 계단 없이 표현됨. 학습 해상도 16×16 → 시험 241×241로 옮겨도 동작 논문 [1]
단점 ①이웃만 더하니 멀리 전달(지지점 ↔ 하중점)에 층이 많이 필요. r을 키우면 이웃 수 폭증 → 메모리 증가
단점 ②원 논문 저자들도 난류(Navier–Stokes)에서 그래프 연산자는 수렴하지 못했고 FNO가 처음 성공했다고 기술 논문 [2]

FNO vs GNO — 한 층에서 정보가 어디까지 가나

FNO = 이퀄라이저

함수 전체를 파동(저음~고음)으로 분해 → 파동마다 학습된 볼륨 R을 곱함 → 다시 합침. 파동 하나가 영역 전체에 걸쳐 있어서 한 층에 전체가 섞임.

GNO = 반상회

각 점이 반지름 r 안 이웃에게 값을 물어 가중 평균. 집(점) 위치가 자유로움. 소식은 한 층에 r만큼만 퍼짐.

"이웃을 본다" = CNN 3×3 필터를 "아무 위치"로 일반화한 것

한 층에서 점 하나가 하는 계산 (순서대로)

#하는 일예 (빨간 점 A)
1이웃 찾기: A에서 거리 r 안에 있는 점을 모두 고름 (학습 아님, 기하 계산)B, C, D, E 4개
2가중치 계산: 이웃마다 상대 위치(Δx, Δy, 거리)와 두 점의 입력값(재료 여부 등)을 κ(MLP)에 넣어 가중치를 얻음κ(B)=0.6, κ(C)=0.1, …
3가중 평균: Σ κ(이웃) × v(이웃) ÷ 이웃 수이웃들의 현재 특징을 섞음
4자기 값 더하고 활성화: v새(A) = σ( W·v(A) + 3의 결과 )A의 새 특징
5모든 점이 동시에 1~4 → 다음 층에서 반복층마다 정보가 r씩 더 퍼짐
학습되는 것: 점마다 따로 외운 숫자가 아니라 κ(MLP)와 W 한 세트. 모든 점·모든 형상이 같은 κ를 씀. 새 메시가 들어오면 1단계(이웃 찾기)만 다시 하고 같은 κ에 넣음 → 그래서 점 개수·배치가 달라도 동작.
FNO와 같은 눈으로 보면: 둘 다 "이웃 값에 가중치를 곱해 더하는" 합성곱의 친척. FNO는 영역 전체 크기의 필터를 주파수(R)로 학습하고, GNO는 반지름 r 크기의 필터를 연속 함수(κ)로 학습. 단, FNO의 필터는 "상대 위치에만 의존"(어디서나 같은 필터)이라 규칙 격자가 필요하고, GNO의 κ는 두 점의 입력값도 받을 수 있어 위치마다 다르게 반응할 수 있음 [1][3].

그래프 용어로 다시 보기 — 노드·엣지

용어GNO에서 의미위 계산에서
노드(node)점 하나. 위치 x, 입력값 a(x)(재료 여부 등), 현재 특징 v(x)를 가짐빨간 점·회색 점
엣지(edge)두 점의 연결. 반지름 r 안의 점끼리만 이음1단계 "이웃 찾기"
엣지 특징상대 위치(Δx, Δy, Δz)·거리·양 끝 점의 입력값2단계 κ의 입력
메시지 전달엣지마다 κ(엣지 특징) × v(이웃)를 노드로 모음3단계 가중 평균

FEM 메시를 쓰면 "같은 요소를 공유하는 절점 쌍"을 엣지로 잡을 수도 있음(MeshGraphNet 계열). 원래 GNO는 메시 연결과 무관하게 반지름 r로 엣지를 만들어 점 배치가 바뀌어도 같은 κ를 씀 [1].

자주 하는 오해 ✕ "좌표 x, Δx를 쓰니까 결국 격자 위에 있는 것 아닌가?" — 아님. 좌표는 연속 공간의 위치(아무 실수, 예: 3.7 mm), 격자는 "점이 간격 h의 자리에만 놓일 수 있다"는 제약. 모든 FEM 메시·점구름도 좌표는 있지만 격자는 아님.
격자가 꼭 필요한 이유GNO는?
CNN가중치를 "칸 자리"(w₁~w₉)마다 저장 → 이웃이 그 자리에 있어야 함Δ를 연속 숫자 입력으로 κ에 넣음 → 어떤 Δ든 가중치가 나옴. 격자 불필요
FNOFFT는 같은 간격으로 놓인 값에서만 정의됨

x 자체가 아니라 Δx(상대 위치)를 쓰는 이유: 같은 모양이 다른 위치에 있어도 같은 계산을 하게 하려고(평행이동 불변). CNN이 어디서나 같은 필터를 쓰는 것과 같은 발상.

자주 하는 오해 ✕ "GNO = 불규칙 점을 규칙 격자로 바꿔 주는 것" — 그건 GINO가 GNO를 쓰는 방식 하나일 뿐. GNO의 정체는 "학습하는 보간": 일반 보간이 "주변 점의 가중 평균, 가중치 = 거리 공식"이라면 GNO는 가중치를 κ(MLP)가 학습. 한 층은 값이 있는 점(입력)과 값을 알고 싶은 점(출력)을 따로 받고, 출력 점을 어디에 두느냐로 역할이 갈림.

빨간 출력 점이 하는 계산은 세 경우 모두 같음(원 안 입력 점의 κ 가중 평균). 원래 GNO 논문 [1]은 ①처럼 메시 위에서 층을 쌓아 PDE 해를 직접 예측. ②·③은 GINO [6]가 FNO를 쓰기 위해 붙인 용도.

GINO = GNO(입·출구) + FNO(가운데) — 둘의 장점을 합친 구조

근거 논문 [6]: GINO는 SDF + 점구름으로 형상을 받고, GNO가 불규칙 점 ↔ 규칙 잠재 격자를 바꾸며 그 위에서 FNO를 돌림. 3D 자동차 표면 압력을 데이터 500개로 학습, 항력 계산에서 GPU CFD 대비 26,000배 속도. → 우리 구조(DeepSDF → 격자 → FNO)와 생각이 같음: 우리는 SDF를 복셀 점유도로 바꿔 바로 FNO에 넣고, GINO는 그 변환을 GNO로 학습.

6PI-GNO — "GNO + 물리 손실". 단, 정해진 모델 하나가 아님

먼저 바로잡을 점: "PINO"는 Li et al. 2021의 특정 방법이지만, "PI-GNO"는 표준 모델명이 아님. 여러 그룹이 비슷한 이름을 각자 다른 구조에 붙임. 발표·대화에서 "PI-GNO를 쓴다"고 하면 어느 것인지 같이 말해야 함.
이름 (출처)무엇우리 관점

핵심 난제 하나: 불규칙 점에서 "물리 손실의 미분"

mGNO 논문 표: 같은 문제에서 물리 손실을 자동 미분으로 구한 경우 1.62e-6, 유한 차분 4.89e-3, 푸리에 미분 4.77e-3 논문 [7]. 즉 "어떻게 미분하느냐"가 정확도를 크게 바꿈.

우리에게 의미 추정: 나중에 GNO로 바꾸더라도 노드가 FEM 메시 절점이면 지금의 Kû − f 잔차를 그대로 쓸 수 있음 → mGNO 같은 미분 장치 없이도 "PI-GNO"가 됨. (이건 우리 추론이며 실험으로 확인한 것은 아님)

① 데이터가 이미 격자

problem.npz·FEM이 2~5 mm 육면체(hex8) 격자. 형상 = 칸 밀도 → FNO 입력과 1:1. 변환 손실 없음.

② 물리 손실이 공짜에 가까움

FEM 코드의 K를 그대로 써서 잔차 계산. 정답 FEM과 같은 이산화 → 모델과 심판(FEM)이 같은 기준.

z → DeepSDF → 격자 → PINO 전체가 미분 가능 → Adam으로 z 갱신 (설계 결정 8번).

9흔한 오해 — 냉정 평가

✕ "FNO는 해상도 무관이니 2 mm로 학습하고 1 mm에 바로 쓰면 된다"

논문의 "제로샷 초해상도"는 매끈한 유동장에서 보인 결과 논문[2][4]. 우리는 형상 경계 자체가 해상도에 따라 바뀜(얇은 막대가 2 mm에선 1칸, 1 mm에선 2칸). 같은 형상이라도 입력이 다름 → 보장 안 됨, 미검증. 그래서 1 mm는 FEM(verify5.py)으로만 판정.

✕ "PINO = 새로운 신경망 구조"

구조는 FNO 그대로. 바뀐 것은 손실 함수(학습법). 추론 속도도 FNO와 같음.

✕ "PI-GNO가 PINO보다 최신이라 더 좋다"

"PI-GNO"는 여러 논문의 서로 다른 모델(6절). 규칙 격자 문제에서 FNO 계열보다 낫다는 일반 근거는 찾지 못함. 장점은 불규칙 형상에 한정.

✕ "물리 손실이 0이면 정답이다"

잔차 Kû − f = 0은 그 격자·그 K에서의 FEM 해와 같다는 뜻. 경계조건·하중 모델이 틀렸으면(예: TV 패드 들림을 고정으로 가정) 물리 손실 0이어도 현실과 다름. 최종 심판은 여전히 FEM + 가정 검토.

✕ "FNO의 modes를 키우면 무조건 정확해진다"

modes 상한은 격자 절반(나이퀴스트). 파라미터가 modes³로 늘어 데이터가 적으면 과적합. 우리 리허설의 병목은 모양이 아니라 크기(강성) 예측이었음 실측 → modes보다 크기 머리·데이터 양이 먼저.
