# 07_입력_1차설계 — 요청(텍스트·스케치·사진) → 1차 설계 + 물리 조건 명세

물리 단계(최적화·수치해석) **앞의 모든 것**을 담당합니다. 사내 환경을 고려해 LLM·GPU 없이 CPU만으로 동작합니다.

```
텍스트 ─ 키워드 규칙 ─┐
스케치/사진 ─ 템플릿 매칭 ─┼→ 템플릿 + 조건 → 설계 명세(spec.json) → 해석 문제(problem.npz) → 물리 단계
                        └→ 1차 설계 CAD(STEP)·도면(DXF/PDF)·STL + 기준 판정(report.json)
```

## 실행

```bash

python run.py --text "울퉁불퉁한 길에서도 안 흔들리게, 최대한 가볍게, S25 울트라" --sketch examples/hand/hand_T07.png --out out/

```

## 물리 단계로 넘기는 것

| 파일 | 내용 |
|---|---|
| `spec.json` | 설계 명세. 영역(지킬 곳·비울 곳·바꿀 곳·강체), 재료, 고정, 대칭, 집중 질량, 하중 케이스, 목적, 제약(유도식 포함), 근거, 가정 |
| `problem.npz` | 요소 라벨(0 설계 / 1 고정부품 / 2 빈 곳 / 3 강체), 강체 강성·질량 배율, 고정 절점, 대칭면 절점, 절점 질량, 하중 벡터와 대칭 조건(S/A) |
| `initial_design.npy` | 1차 설계 밀도(절반 모델, 요소별 0/1) — 최적화 초기값으로 사용 가능 |
| `design_1st.step` | **1차 설계 CAD** (CadQuery/OpenCascade B-rep, 단일 솔리드). 클램프 링·절개·M4 볼트 구멍 2개·팔·받침·폰 클램프 체결 구멍 Ø8 |
| `design_1st_drawing.dxf/.pdf/.png` | **도면**: 제3각법 정면·평면·우측면 + 등각, 주요 치수, 표제란(재료·질량·설계 조건·1차 판정). A4 1:1 기본, 크면 A3 |
| `design_1st.stl` | 1차 설계 전체 모델(대칭 복원, 복셀 기반 메쉬) — 해석 격자 확인용 |
| `report.json` | 입력 해석(발동 규칙·질문), 템플릿 후보 3개, 1차 설계의 기준 판정 |

**최적화 코드 연결**: `opt3d.py` 앞부분(문제 정의)을 아래 한 줄로 바꾸면 같은 변수(`design, solid, post, fixn, plane, topn, tipm, edof, FT …`)가 명세에서 만들어집니다. 기본 템플릿은 현재 `opt3d.py`와 **요소·절점 단위로 동일**합니다(테스트로 확인).

```python
sys.path.insert(0, "../../07_입력_1차설계")
from formproof_input.adapter import opt3d_namespace
globals().update(opt3d_namespace("out/spec.json"))
```

**하나의 형상 출처**: 템플릿 파라미터 → `spec["geometry"]`(해석 격자와 같은 스냅 값) → 해석 격자·STEP·도면이 모두 여기서 나옵니다. 축 방향 팔은 면이 격자선에 오도록 맞춰, 6 mm 팔이 격자에서 4·8 mm로 바뀌는 일을 막았습니다(수정 전 L자 팔 질량 오차 +15~20% → 수정 후 ±3% 이내).
볼트·체결 구멍은 CAD·도면에만 있고 해석 격자에는 없습니다(팀 v7과 같음, `holes_in_analysis: false`).

## 설계 명세 규칙

- 좌표: 핸들바 축 = y축(x=0, z=0), x = 진행 방향, z = 위. 대칭면 y = 55 (팀 프레임 유지), 절반 모델 y ≥ 55.
- 요소 영역은 열린 구간(요소 중심 기준), 절점 선택은 닫힌 구간. **영역 경계가 요소 중심과 겹치면 오류** — `<`/`<=` 차이로 결과가 바뀌는 일을 막습니다.
- 역할 우선순위: 빈 곳 > 강체 > 고정부품 > 설계 영역.
- 모든 수치에 `source`(근거) 또는 `assumed`(가정) 표시. 근거 없는 조건은 보수값으로 대체하고 `assumptions`에 남깁니다.

## 알아둘 점

- 충격 하중에 거치대 자체 관성은 팀 v7과 같게 넣지 않았습니다(`include_self_inertia`). T01에서 넣으면 응력 +1.6%로 작아 기본값은 유지했습니다.
- 손그림 매칭 정확도는 합성 손그림 기준입니다. 실제 손그림으로 다시 재야 합니다.
- 사진 입력은 에지 검출 후 같은 매칭을 쓰지만 시험 전입니다(`--photo`).
- 핸들 직경(25.4·31.8·35)과 폰 클램프 50 g는 가정값입니다.

## 트랙 2 (스케치 CNN) 연결점

템플릿은 `(pad_x0, pad_z0, arm 형식)` 파라미터 공간의 점입니다. CNN은 이 파라미터를 직접 회귀하도록 학습하면 되고, 학습 데이터는 `sketch.template_strokes → perturb → draw_image`로 무한히 만들 수 있습니다. 출력이 같은 파라미터라 `build_spec` 이후는 그대로 씁니다.
